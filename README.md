# MarkMuse

一个功能强大的 Markdown 编辑器，支持自定义主题、文件管理和微信公众号导出。

## ✨ 特性

- 📝 **Markdown 编辑** - 实时预览，支持代码高亮和数学公式
- 📁 **文件管理** - 文件和文件夹的创建、编辑、删除，支持嵌套结构
- 🎨 **主题系统** - 内置多个精美主题，支持自定义 CSS 主题
- 📱 **微信公众号导出** - 一键复制到微信公众号编辑器，完美适配
- 💾 **本地存储** - 使用 IndexedDB 持久化存储，数据安全可靠
- ⌨️ **快捷键支持** - 丰富的快捷键，提升编辑效率

### 保存与 GitHub 推送

- 切换文件、删除或重命名之前，先完成当前稿件保存；保存失败会中止操作并保留稿件。
- 手动或定时推送前都会保存当前稿件，即使关闭了自动保存。
- 增量推送仍然是单向备份，不会自动拉取或删除远程文件。
- 只有远程版本与上次成功同步的版本一致时，才允许上传本地修改。远程有更新、远程文件被删除，或首次同步出现同名但内容不同的文件时，会暂停该文件并提示；其他文件继续处理。
- 相同内容可以直接建立同步基线。基线按仓库、分支和目录分别保存，旧版未区分仓库的记录不会被用于授权覆盖。
- 遇到差异，请先分别备份本地和远程内容，再决定保留哪个版本。当前版本尚未提供自动合并或冲突对比界面。
- “覆盖本地/远程”仍是显式强制替换操作，不受增量推送的版本保护；操作前请备份。这些操作的事务化与恢复机制属于后续改进。

运行保存与推送安全回归测试（使用模拟存储与 GitHub，不会访问实际仓库）：

```bash
npm run test:safety
```

## 🛠️ 技术栈

- **React 18** - UI 框架
- **TypeScript** - 类型安全
- **Vite** - 构建工具
- **Dexie.js** - IndexedDB 封装
- **MarkdownIt** - Markdown 解析
- **Highlight.js** - 代码高亮
- **KaTeX** - 数学公式渲染
- **Tailwind CSS** - 样式框架

## 📖 主要功能

### 文件管理
- 创建、重命名、删除文件和文件夹
- 支持文件夹嵌套
- 自动保存到本地

### Markdown 编辑
- 实时预览
- 代码高亮（支持多种语言）
- 数学公式（行内和块级）
- Emoji 支持
- 快捷命令菜单

### 主题管理
- 内置多个精美主题
- 自定义 CSS 主题
- 主题导入导出
- 默认主题设置

### 导出功能
- 复制到微信公众号（HTML 格式）
- 自动内联样式
- 代码高亮样式保留

## 📝 快捷键

- `Ctrl+B` - 加粗
- `Ctrl+I` - 倾斜
- `Ctrl+U` - 下划线
- `Ctrl+1~6` - 标题（1-6级）
- `Ctrl+K` - 链接
- `/` - 打开快捷命令菜单

更多快捷键请参考应用内的帮助文档。
